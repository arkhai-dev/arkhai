# Security

Do not post credentials or sensitive vulnerability details in a public issue. Use GitHub private vulnerability reporting if the repository owner enables it; otherwise contact the owner through a verified private channel.

This project has not undergone an independent security audit. Browser-local workflow roles are not an authentication boundary. Do not place service credentials in frontend code or use local approvals to authorize real transactions.

Repository hygiene checks cover specific patterns and configuration risks. They do not establish that the application or its dependencies are secure.
